- **Diagnosis:** Viewed both the broken output and the reference image side-by-side to confirm the shape mismatch
- **Fix applied (v2 prompt additions):**
  - Added explicit negative constraints: *"NO rod antennas, NO whip antennas, NO tapered antenna shapes, NO stick antennas"*

- **Result:** v2 correctly shows flat rectangular matte black panel with ALFA NETWORK logo, RP-SMA connector, articulated base bracket

**Key learning:** For dashboard/infographic images, explicit negative shape rules are required to prevent the model from substituting generic antenna illustrations.
