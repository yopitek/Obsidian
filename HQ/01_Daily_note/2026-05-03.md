## ⚙️ 技術架構

### Hyperframes 工作原理
- **Init**：`npx hyperframes init <project-name>` → 選 "Product Promo" template → 跳過 AI skills 安裝（避免 npm hang）
- **Compose**：撰寫 `index.html`（root composition, `data-duration="30"`）+ 各 scene 的 `compositions/scene*.html`
- **Lint**：`npx hyperframes lint` — 檢查 blocking error（✗） vs warning（⚠）
- **Render**：`npx hyperframes render` → 輸出至 `./renders/<timestamp>.mp4`
- **渲染速度**：約 17–24 秒完成 30s 影片（M 系列 Mac, 4 workers）

### 關鍵技術規則（踩過的坑）
| 規則 | 說明 |
|---|---|
| `template_literal_selector` | `querySelector` 不能用 template literal，一律改成 hardcoded string |
| `non_deterministic_code` | `Math.random()` 禁用，改用固定陣列（deterministic） |
| GSAP timeline | 必須 `gsap.timeline({ paused: true })`，並掛到 `window.__timelines["id"]` |
| Asset 路徑 | compositions 內圖片路徑為 `../assets/filename.png` |
| Warnings (88個) | `composition_self_attribute_selector` — non-blocking，正常現象 |
