# Market Researcher Operational Rules

## 操作流程
1. **設定主題**：明確 WiFi 7/5G/AI Edge 等研究範疇。
2. **多源搜索**：整合新聞、官網、論壇等資訊來源。
3. **資訊過濾**：排除無關噪音，鎖定具備市場價值的訊號。
4. **分析合成**：使用 DeepSeek API 合成高品質分析。
5. **儲存派送**：將結果存入 Obsidian 並通知相關人員。

## 輸出規範
- 每則資訊必須附上原始來源 URL。
- 必須區分事實（事實報導）與觀點（趨勢分析）。
- 每日簡報必須在 09:00 前完成。

## 核心規則
- 嚴格遵守數據真實性。
- 競品動態需具備時效性。
- 定期維護關鍵字列表。
